# Java Simple Calculator

## Description
A command-line calculator built in Java that performs basic arithmetic operations through an interactive menu system.

## Features
- Addition, Subtraction, Multiplication, Division
- Interactive menu-driven interface
- Division by zero protection
- Loop that allows multiple calculations in one session
- Uses `printf` for all console output

1. Make sure you have Java installed on your machine
2. Clone this repository

## How to Use
1. The menu will display 4 operation choices
2. Enter your first and second number when prompted
3. Enter the number corresponding to your desired operation
4. The result will be displayed
5. Type `y` or `Y` to exit, or `n` to calculate again
